# 用奶助手 Demo

独立的静态交互演示，包含用奶助手、母乳入库、普通冰箱／Momcozy 小冰箱／冷冻库存、取用、升温计时、喂养记录与供需关系。保留 Air2 设备演示框架。

## 在线预览

https://lyqssx.github.io/milk-assistant-demo/

## 使用

从 Home 页面进入“用奶助手”。当前演示以中文和 mL 为主。数据与硬件识别均用于原型演示；真实相机、NFC 和设备通讯尚未连接。估算计时不能代替实际奶温检查。

页面首次载入使用演示数据，在当前会话中保留流转状态。配件选项和滑动范围使用浏览器本地存储。

## 本地预览

```sh
python3 -m http.server 8080
```

在浏览器中访问 http://localhost:8080/。

## 部署

GitHub Pages 发布 `main` 分支根目录。所有运行资源使用相对路径，支持仓库子路径。`.nojekyll` 保持静态资源按原路径发布。

本版本使用独立的浏览器存储键，避免与同账号下其他 Demo 的偏好设置和批注混用。已移除原型中无法解析、从未生效的历史脚本加载，其他运行链保留。
